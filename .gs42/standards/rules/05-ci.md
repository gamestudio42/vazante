# Continuous integration

After opening or pushing a pull request, read CI yourself. Do not ask
the user for screenshots of GitHub checks.

Typical commands when `gh` can see the pull request:

```bash
gh pr checks
gh pr view --comments
```

If the repository publishes coverage (Codecov or a CI coverage
artifact), open the missing lines and add tests for the behavior you
changed. Prefer covering the failing branch over lowering the threshold.

Report any check that could not be read (missing `gh` auth, private
fork, or CI still running). A green workflow does not replace playing
the slice when the change is about feel, readability, or balance.
