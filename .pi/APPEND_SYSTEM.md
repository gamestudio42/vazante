# GameStudio42 standards

Pi already loads `AGENTS.md`. These lines add the vendored policy.

Read, in order, before changing the game:

1. `.gs42/standards/AGENTS.md`
2. The selected profiles under `.gs42/standards/profiles/`
3. Applicable files under `.gs42/standards/rules/`, including `rules/design/` before a player-facing change
4. The matching `SKILL.md` under `.pi/skills/` or `.gs42/standards/skills/`

Repository files in the current tree remain authoritative for repository-specific conventions.

Do not push, merge, rebase, or force-push without explicit authorization.
Do not delete published games, wipe uploads, or reset production data without approval.
